# Asciinema :simple-asciinema:

??? abstract "Referências"
    - [asciinema docs](https://docs.asciinema.org/getting-started/#__tabbed_1_6)

```bash
# instalação
sudo apt install asciinema

asciinema rec gravacao.cast
# Digitar exit e apertar Enter OU usar o atalho Ctrl + D.
asciinema play minha_gravacao.cast
```
