# Golang :simple-go:

## Compilar

Compilar arquivos com `go build nome-arquivo.go` e executar com `./nome-arquivo.go`
Compila e executa programa (sem criar executável na pasta) com `go run nome-arquivo.go`

Ver documentação dos pacotes e função com `go doc fmt` ou ainda `go doc fmt.Println`.

Declaração e uso de pacotes: a função `main` é o ponto de partida da aplicação:

```go
package main 

import "fmt" 

func main () {
  fmt.Println("Hello World") 
}
```

## Pacotes

Todos os [pacotes padrão do go](https://pkg.go.dev/std).

```go
// importa vários pacotes
import (
  "package1"
  "package2"
)
// apelidos pros pacotes
import (
  p1 "package1"
  "package2"
)
// chama assim
p1.SampleFunc()

/* comentario
multilinha
*/
```

## Tipos de dados

| Tipo         | Descrição                                            | Uso Comum                         |
|--------------|------------------------------------------------------|-----------------------------------|
| **int8**     | Inteiro de 8 bits (valor de -128 a 127)            | Usado quando a economia de espaço é crucial. |
| **int16**    | Inteiro de 16 bits (valor de -32,768 a 32,767)     | Usado para pequenos números.      |
| **int32**    | Inteiro de 32 bits (valor de -2,147,483,648 a 2,147,483,647) | Para números inteiros padrão, como seu exemplo. |
| **int64**    | Inteiro de 64 bits (valor de -9,223,372,036,854,775,808 a 9,223,372,036,854,775,807) | Para trabalhar com grandes números inteiros. |
| **uint8**    | Inteiro sem sinal de 8 bits (valor de 0 a 255)      | Usado para valores não negativos pequenos. |
| **uint16**   | Inteiro sem sinal de 16 bits (valor de 0 a 65,535) | Para contagens não negativas menores. |
| **uint32**   | Inteiro sem sinal de 32 bits (valor de 0 a 4,294,967,295) | Uso geral para números inteiros não negativos. |
| **uint64**   | Inteiro sem sinal de 64 bits (valor de 0 a 18,446,744,073,709,551,615) | Para números inteiros não negativos grandes. |
| **float32**  | Ponto flutuante de 32 bits                            | Para números decimais precisos com menos memória. |
| **float64**  | Ponto flutuante de 64 bits                            | Para a maioria dos cálculos de precisão. |
| **complex64**| Número complexo com partes reais e imaginárias de 32 bits | Para cálculos com números complexos. |
| **complex128**| Número complexo com partes reais e imaginárias de 64 bits | Para cálculos complexos mais precisos. |
| **string**   | Sequência de caracteres                               | Para armazenar texto.             |
| **bool**     | Tipo booleano (verdadeiro ou falso)                  | Para lógicas condicionais.        |
